# Trainings Repository

This is a collection of training programs for AI-assisted software development.

## Content Rules

- Each program lives in its own directory with a `TRAINING-PLAN.md` or equivalent main document
- Programs are self-contained — all materials for a program stay in its directory
- Write for an audience of working software engineers
- Keep language practical and direct — no marketing fluff

## Formatting

- Markdown only
- Use tables for structured comparisons
- Use heading hierarchy consistently (H1 = title, H2 = sections, H3 = subsections)
- Code blocks with language tags for all code examples
