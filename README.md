# AI Trainings

Hands-on training programs and guides for AI-assisted software development. Covers Claude Code, GitHub Copilot, and AI coding workflows — from first setup to advanced techniques.

Created with friends during weekends and holidays. Open source, MIT licensed.

## What's Here

### Programs

Structured multi-day training programs with mentor support. Each includes a training plan, cheat sheets, and assessments.

| # | Program | What You'll Learn | Duration |
|---|---------|-------------------|----------|
| 01 | [VS Code Copilot](./programs/01-copilot-vscode/) | Copilot completions, chat, edit mode, agent mode, custom instructions | 4 days |
| 02 | [Claude Code + Go](./programs/02-claude-code-golang/) | Go fundamentals with AI-assisted development, from zero to a working service | 9 days |
| 03 | [Claude Code + Next.js](./programs/03-claude-code-nextjs/) | Claude Code mastery for fullstack engineers — planning mode, parallel tabs, codebase hardening | 4 days |

### Guides

Self-service reference materials. Pick what you need, no mentor required.

| # | Guide | What It Covers |
|---|-------|----------------|
| 01 | [Hackathon 2026](./guides/01-hackathon-2026/) | Claude Code technique comparison for hackathons — 6 techniques, 5 accelerators, evaluation rubric |
| 02 | [Writing a CLAUDE.md](./guides/02-claude-md-authoring/) | How to author a repo instruction file the agent actually follows — fill-in template + the six rules that make rules stick |

## Where to Start

- **New to AI coding?** Start with [01-copilot-vscode](./programs/01-copilot-vscode/) — lowest barrier to entry.
- **Know Copilot, want Claude Code?** Jump to [03-claude-code-nextjs](./programs/03-claude-code-nextjs/) if you're a JS/TS dev, or [02-claude-code-golang](./programs/02-claude-code-golang/) if you want to learn Go at the same time.
- **Preparing for a hackathon?** Go straight to [Hackathon 2026 Techniques Menu](./guides/01-hackathon-2026/TECHNIQUES-MENU.md).
- **Setting up a repo for AI agents?** Grab the [CLAUDE.md template](./guides/02-claude-md-authoring/).
